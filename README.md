# Colonial Prison Statistics Explorer — v7

Static, GitHub-Pages-ready research platform centered on Mandatory Palestine and connected to British imperial and comparative prison datasets.

Current build: **1,977 observations, 41 jurisdictions, 39 loaded sources / 46 registered sources, 92 raw measures, and 19 research concepts**.

The platform exposes every registered source, every loaded observation, every raw measure and every source–measure mapping. Mandatory Palestine remains the fixed analytical baseline. Clicking a chart point opens full data lineage to the source URL, locator, source record ID and transformation.

v7 includes a Palestine dashboard, aligned comparison lab, source atlas, measure atlas, source–concept network, global and facility maps, full data explorer, QA/provenance view and downloadable mapping layers. Annual, 3/5-year moving averages, period averages, Index 100 and cumulative change are supported.

Validation: **22/22 automated tests pass**; 1,977/1,977 observations have complete provenance; full Chromium runtime QA completed with no page, console or chart-render errors.

Open locally with `פתח_את_המערכת.html`, or deploy with the included GitHub Pages workflow. See `README_HE.md`, `docs/SOURCE_MAPPING_V7.md`, and `docs/SYSTEM_QA_V7.md`.
