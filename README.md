# Colonial Prison Statistics Explorer v8.3

GitHub Pages ready. Upload the **contents** of this project folder to a repository root. Set Settings → Pages → Source: **GitHub Actions**. The workflow publishes `site/` to the Pages URL.

At repository root `index.html` redirects local preview to `site/index.html`. The deployed `site/index.html` is the production entry point.

The `ui/` folder is the editable UX source; `pipeline/enrich_v8.py` regenerates and updates `site/`. See `README_HE.md` for full Hebrew instructions.
