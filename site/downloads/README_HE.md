# Colonial Prison Statistics Explorer — v7

מערכת מחקר סטטית, מוכנה ל־GitHub Pages, לניתוח מערכת הכליאה בפלסטין המנדטורית ולהשוואתה למערכות כליאה במרחבים בריטיים ואימפריאליים אחרים.

## פתיחה

לחצו פעמיים על **`פתח_את_המערכת.html`**. המערכת עובדת כאתר סטטי, ללא localhost וללא בחירת port.

## מצב הבנייה

- **1,977 observations**
- **41 מרחבים**
- **39 מקורות טעונים מתוך 46 רשומים**
- **92 מדדים**
- **19 מושגים מחקריים**
- **1,135 observations של פלסטין**

## מה חדש ב־v7

- כל מקור רשום מופיע באטלס, גם אם הוא עדיין refreshable.
- כל מדד מופיע באטלס המדדים וב־Data Explorer.
- כל צמד מקור–מדד ממופה למושג, בסיס זמן, יחידה ודרגת השוואה.
- פלסטין נשארת קבועה בהשוואות.
- נוספו יותר מ־27 גרפים/צירי זמן לפלסטין, מעבדת השוואה רב־שנתית, אטלס מקורות, אטלס מדדים, רשת מקור–מושג, מפה, מפת מוסדות, מטריצות כיסוי וסייר נתונים מלא.
- לחיצה על נקודה פותחת שרשרת provenance מלאה ומציעה נתונים ומקורות קשורים.
- ערכי זמן נתמכים: שנתי, ממוצע נע 3/5 שנים, ממוצע רב־שנתי, Index 100 ושינוי מצטבר.
- heatmaps נבנו מחדש כמטריצות marker יציבות ל־file:// ול־GitHub Pages.

## מבנה המערכת

1. **פלסטין** — מערכת וזרמים; מוסדות ומרחב; עבודה/משמעת/רצידיביזם; אירועים והערות.
2. **השוואה** — פלסטין מול מרחבים אחרים, עם יישור לפי מושג ובסיס זמן.
3. **אטלס מקורות** — כל 46 המקורות, כל 92 המדדים ורשת הקשרים.
4. **מפה** — מרחבים, מוסדות וכיסוי כרונולוגי.
5. **נתונים** — כל 1,977 ה־observations עם סינון והורדה.
6. **איכות וקישוריות** — provenance, Grades, QA, כיסוי וקשרים.
7. **הורדות** — הנתונים, המילונים וכל שכבות המיפוי.

## GitHub Pages

ה־repository כולל workflow. לאחר העלאה ל־GitHub בחרו:

`Settings → Pages → Source → GitHub Actions`

ה־workflow בונה מחדש את הנתונים והמיפויים, משחזר את ממשק v7, בודק JavaScript, מריץ את הבדיקות ומפרסם את `site/`.

## רענון מקומי

Windows: `UPDATE_DATA_WINDOWS.bat`  
macOS: `UPDATE_DATA_MAC.command`

או:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r pipeline/requirements.txt
python pipeline/enrich_v7.py
node --check site/assets/app.js
python -m unittest discover -s tests -v
```
